# 微信开发者工具本机演示

在项目根目录运行 `npm run preview:miniapp`，保持终端运行。脚本输出三个目录，分别在微信开发者工具中作为独立项目导入。副本使用游客 AppID，项目名标有顾客、员工或店主。员工和店主从首页「管理」登录，演示口令由启动命令显示。

1. 在顾客副本添加商品、预览自取报价、确认下单，再打开「我的订单」完成模拟支付。
2. 在员工副本登录并刷新订单，接单后标记「待自取」。切回顾客副本刷新订单，查看自取码。
3. 在员工副本输入自取码完成核销。顾客端刷新后显示「已完成」。
4. 在店主副本打开「经营统计」，可查看同一笔模拟收款及完成销量。

每次启动会在 Git 忽略的 `.local/miniapp-preview` 下生成一组三个项目。组内副本共享同一个本机服务，服务结束后虚构数据随进程清空。再次启动时导入新输出的目录。使用 Ctrl+C 可以停止本机服务。

服务只监听本机回环地址。副本使用每次启动时生成的角色令牌和独立缓存命名空间，开发者工具项目配置中关闭域名校验供模拟器访问本机服务。请把这些副本用于本机模拟器演示，避免上传到微信平台或分享其中的生成配置。
