# 地址删除接入

日期：2026-10-28。原微信地址列表已通过统一客户端接入删除；沿用后端已有软删除、版本校验、归属检查和默认指针清理规则。本轮没有改动云配置或部署数据库。

## 确认和版本

删除操作先展示确认框。取消、确认框失败、确认前页面隐藏或列表已刷新时不发送删除。连续点击只保留一个确认框和一次操作。

确认针对页面中已展示的地址ID及版本；提交只含addressId、expectedVersion、requestId。确认期间地址被编辑，后端拒绝旧版本；列表刷新后，用户需重新点击并确认，页面不会自动删除新版本。

删除当前默认地址时清除用户默认指针。如果默认已改成另一条地址，则保留新选择。删除是软删除，不改动历史订单的地址快照。

## 保存和删除的恢复隔离

miniapp-address-editor在同一运行时中管理一份待确认地址操作，kind为save或remove。保存与删除共用并发锁；结果未知时，禁止另一个意图覆盖原操作。

删除请求成功但响应丢失时，列表可能已不显示目标，仍会展示“重试原删除”。retryRemove复用原地址ID、版本和requestId，由服务端返回原结果；不重新选择地址，不再弹出一个针对新版本的确认框，也不再次增加地址版本。

原retry仅重试保存，retryRemove仅重试删除。新增/编辑表单遇到待确认删除时提示返回列表处理，不把删除结果当成保存成功。已有待确认保存时，列表也不会通过删除按钮或删除重试按钮执行它。

待确认删除只记录ID、版本及请求ID，不保存联系人、电话、完整地址或口令令牌。记录仅在运行时内存中；页面重建可恢复，进程关闭或设备切换后不承诺恢复。重新进入应先核对服务器列表。
